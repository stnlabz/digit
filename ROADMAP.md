# Roadmap

## Current objective

Define, implement, and qualify Digit's governing core in ISO C.

## Sequence

1. Maintain alignment with approved STN-LABZ policy.
2. Complete core requirements and lifecycle definitions.
3. Evaluate historical source only for still-valid engineering concepts.
4. Implement the minimal approved ISO C core.
5. Execute the 20 mandatory core qualification tests, including fail-safe
   validation.
6. Stabilize the qualified core.
7. Add mission-specific capabilities only through approved module governance.

Dates, releases, and capability commitments not established by approved plans
remain `UNKNOWN`.
