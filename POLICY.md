# Policy

Digit is governed by approved STN-LABZ policy and authorized human direction.
Repository documentation and source code do not create or override policy.

Applicable approved policies provided for current development include:

- STN-LABZ General Orders
- `20260730.0 — Digit: Foundation`
- `20260801.1 — KISS Theory`
- `20260814.2 — Mandatory AI Annotation Policy`
- `GH-001 — GitHub Repository Requirements`

When a lower-level artifact conflicts with approved policy, policy controls. An
unresolved assignment or requirement remains `UNKNOWN` pending authorized human
direction.
